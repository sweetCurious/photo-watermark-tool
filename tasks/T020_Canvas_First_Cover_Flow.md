# T020 Canvas-first Cover Flow

## Goal

将批量处理流程改为先选择统一画布，再添加照片。所有照片保持原比例缩放并覆盖整个画布。

## Rules

- 进入编辑器后先选择竖版或横版画布。
- 一批照片统一使用当前画布方向和尺寸。
- 图片采用等比例 Cover 缩放，完整填满画布。
- 画布比例与照片不同时，超出画布的边缘居中裁切。
- 不拉伸、不留白、不生成模糊背景。
- Logo、底栏、JPG 与 ZIP 导出规则保持不变。

## Acceptance

- 未选择画布时不能进入照片上传步骤。
- 预览与批量导出使用同一画布。
- 横图和竖图混合导入时，所有结果尺寸一致。
- Build、Lint、Type Check 全部通过。
