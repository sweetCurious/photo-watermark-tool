# T022 Safe Composition Mode

## Goal

增加明确的构图编辑状态，避免用户在预览照片时误拖动构图。

## Scope

- 默认锁定照片位置。
- 双击照片或点击“调整构图”进入编辑状态。
- 编辑状态显示九宫格辅助线。
- 编辑状态允许拖动和缩放照片。
- 提供完成、取消、恢复居中。
- 支持按 Escape 取消本次构图。
- 取消后恢复进入构图模式前的位置与缩放。

## Acceptance

- 非编辑状态不能拖动照片。
- 切换照片时自动退出构图模式。
- 完成后保留构图，取消后恢复构图。
- Build、Lint、Type Check 全部通过。
