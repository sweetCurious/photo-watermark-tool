# T019 Editor Workflow Refresh

## Goal

在不改变图片处理、导出规格和纯前端架构的前提下，改善批量水印编辑器的操作效率。

## Scope

- 压缩图片列表的信息密度，让用户能快速切换和删除照片。
- 预览画布自动适应可用空间，并保留简单缩放能力。
- 设置面板自动跟随当前照片的横竖方向，不再要求手动切换模板。
- 强化“添加照片 → 设置品牌 → 处理导出”的流程提示。
- 优化页头、底部操作栏和空状态的视觉层级。

## Out of Scope

- 图片处理算法
- 输出尺寸默认值
- JPG 与 ZIP 导出规则
- 新增依赖或服务端能力

## Acceptance

- Build、Lint、Type Check 全部通过。
- 当前照片切换时，设置面板方向同步更新。
- 不同窗口尺寸下，预览默认完整可见。
- 原有上传、删除、处理、取消和下载功能保持可用。
