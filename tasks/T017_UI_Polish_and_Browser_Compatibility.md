# T017 UI Polish and Browser Compatibility

## Objective

完成 UI 细节优化和主流浏览器兼容检查。

## Scope

包含：

- Chrome
- Edge
- Safari
- Focus 状态
- Empty State
- Disabled State
- Hover State

不包含：

- 移动端适配

## Requirements

桌面端最小宽度：

- 1280px

移动端不支持，可显示提示。

## Files Suggested

- UI 相关组件
- `src/styles/global.css`

## Acceptance Criteria

- [ ] 三栏布局稳定
- [ ] 空状态清晰
- [ ] 按钮状态正确
- [ ] 键盘 focus 可见
- [ ] Chrome/Edge/Safari 基本可用

## Commit Message

```text
style: polish ui and browser compatibility
```
