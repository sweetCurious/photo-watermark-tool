# REVIEW_TASK

Review the current implementation against the current task.

Read:

- Current task file
- AGENTS.md
- docs/PRD.md
- docs/UI_SPEC.md
- docs/TECH_SPEC.md
- docs/PROJECT_RULES.md

Check:

- Did the implementation complete only the current task?
- Did it avoid future tasks?
- Did it follow the required tech stack?
- Did it avoid backend/API/cloud?
- Did it avoid unrelated file changes?
- Did it pass lint?
- Did it pass type check?
- Did it pass build?
- Are there any console errors?
- Are there any TypeScript any usages?
- Are there any oversized components?
- Are there unnecessary dependencies?

Return:

1. Pass / Fail
2. Issues found
3. Required fixes
4. Files that need modification
5. Final commit message

Do not implement new features during review.
