# CONTINUE_TASK

Continue the Photo Watermark Tool project.

First:

1. Read AGENTS.md.
2. Read docs/TASK_INDEX.md.
3. Identify the next unchecked task.
4. Read that task file.
5. Read related docs only if needed.

Then:

Complete the next unchecked task only.

Rules:

- Do not skip tasks.
- Do not implement future tasks.
- Do not modify unrelated files.
- Do not refactor unless required by the task.
- Keep the existing architecture unchanged.
- Run lint.
- Run type check.
- Run build.
- Update docs/TASK_INDEX.md.
- Update CHANGELOG.md if needed.

Return:

- Completed task ID
- Summary
- Changed files
- Test result
- Commit message
